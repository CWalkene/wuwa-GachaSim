# 鸣潮抽卡模拟-概率分布生成器

本项目通过使用官方公示的抽卡概率，针对用户需要的角色共鸣链数量与专武数量，进行`一百万`次（可调节）蒙特卡洛方法的抽卡模拟，计算最终达到目标所需要的抽数，最后生成概率统计图（包括频率分布直方图与累积概率折线图），并标出期望、众数、模拟最大抽卡数、理论最大抽卡数，供用户做抽卡规划。

底层使用 `Numba` 的 `njit` 实现即时编译与并行计算，突破 Python 原生性能瓶颈，实现百万级模拟的秒级响应。

已集成余波珊瑚兑换共鸣链机制，抽卡模拟将始终采用最优策略计算所需抽数：

> 1. 抽出角色本体
> 2. 抽取目标数量的专武
> 3. 继续抽取角色共鸣链，逐抽检测珊瑚能否兑换共鸣链。

项目将结合用户现有的四星角色链数与常驻五星角色链数，计算抽卡过程中的珊瑚产出。故相关内容需要手动配置。

将以下内容根据用户情况填入项目根目录下的`gacha_config.json`（数字代表共鸣链数量，`-1`代表未获得）
